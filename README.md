# NLP_Project_CTAI

How to use this repo?
Firstly, you need to git

```bash
git clone https://github.com/IntArchive/NLP_Project_CTAI.git
```

Then change working directory to `NLP_Project_CTAI`. Use `uv` to create virtual environment.

Activate virtual environment
```bash
./.venv/Scripts/activate
```

Run the program
```bash
python main.py
```
